# namelet

Tiny, flexible name generator for JavaScript and TypeScript.

> 🚧 Coming soon. This library is still in development and isn’t ready to use.

## Planned features

- Built-in word lists and custom dictionaries
- Configurable separators, length, and capitalization
- Seeded generation for repeatable results
- TypeScript support
- Minimal bundle size

Features and API may change as development progresses.
